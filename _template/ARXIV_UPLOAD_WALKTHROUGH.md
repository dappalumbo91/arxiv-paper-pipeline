# arXiv upload walkthrough — {{SLUG}}

You upload in Chrome yourself (no automation).

1. https://arxiv.org/submit  
2. Upload `arxiv_source_v1.zip` (TeX process)  
3. Preview PDF  
4. Paste:

| Field | File |
|-------|------|
| Title | `title.txt` |
| Authors | {{AUTHOR}} |
| Abstract | `abstract.txt` |
| Comments | `comments.txt` |
| Primary | {{PRIMARY_CATEGORY}} |

5. Cross-lists as planned  
6. Accept license → Submit  

If endorsement required for the category, request it before finishing.
